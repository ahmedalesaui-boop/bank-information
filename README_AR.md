# بنك المعلومات الشخصية — مشروع Android

هذا المشروع يحوّل ملف HTML المرفق إلى تطبيق Android يعمل محلياً دون اتصال بالإنترنت.

## إنشاء APK من الآيفون عبر GitHub
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع محتويات هذا الملف المضغوط إلى المستودع (يجب أن يكون مجلد `.github` موجوداً).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Android APK** ثم **Run workflow**.
5. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
6. نزّل `bank-information-apk` ثم افتح ملف APK على هاتف Android وثبّته.

## ملاحظات
- التطبيق لا يطلب إذن الإنترنت ولا يحتاج اتصالاً لتشغيله.
- بيانات الموظفين تُحفظ في مساحة تخزين WebView المحلية على الجهاز.
- استخدم زر النسخة الاحتياطية داخل التطبيق واحتفظ بنسخة JSON في مكان آمن.
- حذف التطبيق أو مسح بياناته قد يؤدي إلى فقدان البيانات المحلية؛ احتفظ بنسخة احتياطية.
- المرفقات في النسخة الحالية تُسجل أسماء الملفات فقط كما في ملف HTML الأصلي؛ لا تُخزّن محتويات الملفات فعلياً.
